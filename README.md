# Новичок — трекер адаптации первых 90 дней

Для кого: непосредственный руководитель новичка (старший склада, директор магазина, РОП) и HR.
Что делает: каждое утро вкладка «Сегодня» показывает, с кем из новичков поговорить и о чём; руководитель записывает встречу за 1 минуту (настроение 1–5, 2 вопроса да/нет, заметка), риск пересчитывается.

Запуск: `node server.mjs` → http://localhost:3000 (Node 20+, зависимостей нет). Тесты: `node test.mjs`.
Данные вымышленные (`seed.mjs`), хранятся в `data.json`; сброс: `POST /api/reset`.

Правила риска — в `risk.mjs`. Веса — гипотеза, не обученная модель.
Приём из Битрикс24: `POST /api/hire {name, role, managerId, hireDate}` — заглушка под исходящий вебхук, с реальным порталом не проверялась.
